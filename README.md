台語小辭典。大字查詞、真人錄音、每日複習。Made By 冷踢踢。

[直接使用](https://lenteyyy.github.io/taigi-pocket/)

搜尋接受繁簡漢字、臺羅、白話字與華語意思。「坏小子／壞小子」可找到「歹囝 pháinn-kiánn」。原詞精確比對優先，再比對繁簡字形與華語別稱；查不到詞目時，改查釋義、華語例句與對應詞。選定分類後，若輸入的詞在該分類查無結果，會自動搜尋全部分類並顯示提示。顯示文字保留原始繁體內容。

支援漢字、臺羅、白話字與數字調號，提供收藏、自建詞表、私人筆記、逐詞標音、六種練習方式及十三個臺羅單元。每日新詞與複習目標分開設定，預設 10／20；達標後可繼續學習，詞表全部學過也能自由複習。字級預設 24 px，可在右上角「設定 → 字級大小」調整為 20–28 px；音量預設 80%。七課共 693 個詞，其中 682 個有釋義可出題。沒有 OCR，沒有帳號，也沒有付費牆。

查詞在瀏覽器處理，收藏、筆記與進度留在目前瀏覽器。換裝置或網址前，先在「閱讀設定與備份」匯出 JSON，再於新網址匯入；紀錄不會自動同步。

看漢字選詞義時，出題即顯示詞目的臺羅；桌機以左右配置優先顯示題目與選項，例句置於選項下方。查詞、學習題目與答題回饋中的例句都顯示原始繁體華語翻譯。詞目、課程與 17,907 筆例句皆在站內播放原音，需要網路。例句優先使用已核對的教育部網址，其餘由 ChhoeTaigi 公開鏡像提供原檔；來源失敗時自動改用備援，不跳轉網頁。開始、繼續及換詞時自動播放；選完答案後，不論對錯，先讀正確詞目，再讀第一筆有錄音的例句。沒有例句錄音就只讀詞目；翻卡模式仍由使用者自行評分。看詞義辨音會依序播放各選項，臺羅聽辨換題也會播放。暫停、換詞或離開學習即停止上一段錄音。標音顯示詞典本調與候選讀音，不是自動翻譯或完整變調。若瀏覽器攔截自動播放，點一次播放鈕再繼續。

本機使用 Python 3，無須安裝套件：

```sh
git clone https://github.com/lenteyyy/taigi-pocket.git
cd taigi-pocket
python3 server.py
```

開啟 http://127.0.0.1:8765/ 。只想預覽靜態版，可用 python3 -m http.server 8767 --directory site。

開發與檢查使用 Node.js 22 以上：

```sh
npm ci
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run build
```

GitHub Pages 由 Actions 發布 dist/；部署前會執行測試。純靜態版以 Web Worker 與 sql.js 查詢壓縮詞典，初次需下載約 6 MB 主詞典；約 2.1 MB 補充詞典按需載入。沒有把 Python 後端放上 Pages。
